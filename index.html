📁 Comandos Básicos de Linux

ls Fácil

Listar contenido de directorios

$ ls [opciones] [directorio]
Ejemplos:
• ls -l - Lista detallada con permisos
• ls -la - Muestra todos los archivos (incluidos ocultos)
• ls -lh - Tamaño en formato legible
• ls -t - Ordenar por fecha de modificación
$ ls -lh
total 4.0K
-rw-r--r-- 1 user user 1.2K Aug 18 10:30 archivo.txt
drwxr-xr-x 2 user user 4.0K Aug 18 10:25 documentos

cd Fácil

Cambiar de directorio

$ cd [directorio]
Ejemplos:
• cd /home - Ir al directorio /home
• cd .. - Subir un nivel
• cd ~ - Ir al directorio home del usuario
• cd - - Ir al último directorio visitado

cp Fácil

Copiar archivos y directorios

$ cp [opciones] origen destino
Ejemplos:
• cp archivo.txt copia.txt - Copiar archivo
• cp -r carpeta/ copia_carpeta/ - Copiar directorio recursivo
• cp -i archivo.txt destino/ - Preguntar antes de sobrescribir

mv Fácil

Mover o renombrar archivos

$ mv [opciones] origen destino
Ejemplos:
• mv viejo.txt nuevo.txt - Renombrar archivo
• mv archivo.txt /home/user/ - Mover archivo
• mv *.txt documentos/ - Mover todos los .txt

rm Medio

Eliminar archivos y directorios

$ rm [opciones] archivo
Ejemplos:
• rm archivo.txt - Eliminar archivo
• rm -r carpeta/ - Eliminar directorio recursivo
• rm -f archivo.txt - Forzar eliminación sin preguntar
⚠️ ¡Cuidado! No hay papelera de reciclaje

mkdir y rmdir Fácil

Crear y eliminar directorios

$ mkdir [opciones] directorio
$ rmdir directorio
Ejemplos:
• mkdir proyectos - Crear directorio
• mkdir -p a/b/c - Crear estructura de directorios
• rmdir directorio - Eliminar directorio vacío

🔒 Permisos y Propiedad

chmod Medio

Cambiar permisos de archivos

$ chmod [opciones] permisos archivo
Sistema numérico:
• 4 = lectura (r)
• 2 = escritura (w)
• 1 = ejecución (x)

Ejemplos:
• chmod 755 script.sh - rwxr-xr-x
• chmod 644 archivo.txt - rw-r--r--
• chmod +x script.sh - Agregar ejecución
• chmod -R 755 carpeta/ - Recursivo

chown Medio

Cambiar propietario y grupo

$ chown [usuario]:[grupo] archivo
Ejemplos:
• chown usuario archivo.txt - Cambiar propietario
• chown usuario:grupo archivo.txt - Cambiar ambos
• chown -R usuario:grupo carpeta/ - Recursivo

sudo Fácil

Ejecutar como superusuario

$ sudo comando
Ejemplos:
• sudo apt update - Actualizar paquetes
• sudo systemctl restart nginx - Reiniciar servicio
• sudo -i - Iniciar sesión como root

📝 Manipulación de Texto

grep Medio

Buscar patrones en texto

$ grep [opciones] patrón archivo
Ejemplos:
• grep "error" log.txt - Buscar "error"
• grep -i "error" log.txt - Búsqueda insensible
• grep -r "pattern" /dir/ - Búsqueda recursiva
• grep -n "text" file.txt - Mostrar números de línea
$ grep -n "admin" usuarios.txt
3:admin:x:0:0:root:/root:/bin/bash
15:webadmin:x:1001:1001::/home/webadmin:/bin/bash

cat, less, more Fácil

Ver contenido de archivos

$ cat archivo
$ less archivo
$ more archivo
Diferencias:
• cat - Muestra todo el contenido
• less - Navegación página por página (q para salir)
• more - Similar a less pero menos funcionalidades
• tail -f log.txt - Ver últimas líneas en tiempo real

sed Difícil

Editor de flujos

$ sed 's/patrón/reemplazo/' archivo
Ejemplos:
• sed 's/viejo/nuevo/g' archivo.txt - Reemplazar
• sed -n '5,10p' archivo.txt - Líneas 5-10
• sed '/pattern/d' archivo.txt - Eliminar líneas

awk Difícil

Procesamiento de texto estructurado

$ awk '{acción}' archivo
Ejemplos:
• awk '{print $1}' archivo.txt - Primera columna
• awk -F: '{print $1}' /etc/passwd - Usuarios
• awk '/error/ {print $0}' log.txt - Filtrar

⚙️ Sistema y Procesos

ps y top Fácil

Ver procesos del sistema

$ ps [opciones]
$ top
Ejemplos:
• ps aux - Todos los procesos
• ps -ef | grep nginx - Buscar proceso
• top - Monitor en tiempo real
• htop - Versión mejorada de top

kill Medio

Terminar procesos

$ kill [señal] PID
Señales comunes:
• kill 1234 - SIGTERM (terminación amigable)
• kill -9 1234 - SIGKILL (forzar)
• killall nginx - Matar por nombre
• pkill -f pattern - Matar por patrón

df y du Fácil

Espacio en disco

$ df [opciones]
$ du [opciones] [directorio]
Ejemplos:
• df -h - Espacio libre en discos
• du -sh carpeta/ - Tamaño de directorio
• du -ah | sort -rh | head -10 - Top 10 más grandes

free Fácil

Memoria RAM

$ free [opciones]
Ejemplos:
• free -h - Memoria en formato legible
• free -m - Memoria en MB
$ free -h
total used free shared buff/cache available
Mem: 7.7G 2.1G 3.2G 156M 2.4G 5.1G
Swap: 2.0G 0B 2.0G

🌐 Red y Conectividad

ping Fácil

Verificar conectividad

$ ping [opciones] host
Ejemplos:
• ping google.com - Ping continuo
• ping -c 4 google.com - 4 paquetes
• ping -i 2 host.com - Intervalo de 2s

curl y wget Medio

Transferencia de archivos

$ curl [opciones] URL
$ wget [opciones] URL
Ejemplos:
• curl https://api.example.com - GET request
• curl -O https://ejemplo.com/file.zip - Descargar
• wget https://ejemplo.com/file.zip - Descargar
• wget -r https://site.com - Descarga recursiva

ssh Medio

Conexión remota segura

$ ssh [usuario]@[host]
Ejemplos:
• ssh user@192.168.1.100 - Conexión básica
• ssh -p 2222 user@host - Puerto personalizado
• ssh -i clave.pem user@host - Con clave privada
• scp archivo.txt user@host:/path/ - Copiar archivos

netstat y ss Difícil

Información de red

$ netstat [opciones]
$ ss [opciones]
Ejemplos:
• netstat -tuln - Puertos escuchando
• ss -tulpn - Versión moderna
• netstat -rn - Tabla de enrutamiento
• ip addr show - Interfaces de red

🚀 Comandos Avanzados

find Difícil

Buscar archivos

$ find [ruta] [expresión]
Ejemplos:
• find /home -name "*.txt" - Buscar por nombre
• find . -type f -mtime -7 - Modificados en 7 días
• find /var -size +100M - Archivos >100MB
• find . -name "*.log" -delete - Buscar y eliminar

tar Medio

Comprimir y descomprimir

$ tar [opciones] archivo.tar [archivos]
Ejemplos:
• tar -czvf archivo.tar.gz carpeta/ - Comprimir gzip
• tar -xzvf archivo.tar.gz - Extraer gzip
• tar -cjvf archivo.tar.bz2 carpeta/ - Comprimir bzip2
• tar -tvf archivo.tar - Ver contenido

cron Difícil

Tareas programadas

$ crontab -e # Editar cron
$ crontab -l # Listar cron
Formato: minuto hora día mes día_semana comando

Ejemplos:
• 0 * * * * /script.sh - Cada hora
• 0 0 * * * /backup.sh - Diario a medianoche
• */5 * * * * /check.sh - Cada 5 minutos

grep | awk | sed (Pipes) Difícil

Combinar comandos

$ comando1 | comando2 | comando3
Ejemplos:
• ps aux | grep nginx | awk '{print $2}'
• cat log.txt | grep ERROR | wc -l
• ls -l | grep "^-" | wc -l - Contar archivos
$ cat /var/log/auth.log | grep "Failed password" | awk '{print $11}' | sort | uniq -c | sort -rn
45 192.168.1.100
23 10.0.0.50
12 172.16.0.25
